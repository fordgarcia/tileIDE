# v0.3 — Plugins + Themes (Gate 2)

> **Status:** planned · Depends on: v0.2.

## Goal
A plugin system and importable VS Code themes **without** breaking the "lightweight" promise. (TileIDE is built from scratch in Rust; it does not run VS Code API extensions. See `../project_context.md` T1.)

## Scope
**Language support**
- Built-in LSP clients: Python, JS/TS, C/C++, Java, Rust (servers installed by the user; TileIDE detects and starts them).
- Diagnostics, hover, completion, go-to-definition shown in tiles and the editor.

**Plugins (called "Extensions" in the UI)**
- Sidebar **Extensions** section: search, install, enable/disable, per-workspace on/off/on-demand.
- Plugin host: sandboxed (WASM) or out-of-process over RPC **[VERIFY choice]**; lazy activation; warning on "activate always".
- **Weight meter v1:** startup time, RAM, CPU per plugin, with a suspend button.
- Public **compatibility list**: what imports and plugins are tested, and what does not work.

**Import of VS Code declarative content (from Open VSX)**
- Themes, TextMate grammars, snippets, keybindings. No JavaScript is run.

**Themes**
- Sidebar **Themes** section: list local themes, preview live, apply per workspace or globally.
- Themes are **mods** (data-only Lua in the strict sandbox, no event hooks), not plugins.
- Theme token ⇄ VS Code theme key mapping for imported VS Code themes.
- **Background picker (S1f)** inside Themes: all modes (see-through, desktop, image, gradient, solid, per-workspace), sliders, live preview, legibility warning.

## Out of scope
Run/debug, toolchains, mod registry and sharing, running VS Code API extensions.

## Gate 2
With **15+ plugins/imports** installed, idle RAM and cold start stay within the budget from Gate 1. If not, strengthen the enforcement levers (`../project_context.md` §6.5) before adding any feature.

## Risks
- Users expect VS Code extensions to just work (T1). The compatibility list must be honest and visible.
- Plugin host choice (WASM vs out-of-process) is hard to change later. Decide with a small prototype.
- Plugin views have nowhere to live in a sidebar-less code region.
