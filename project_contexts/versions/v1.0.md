# v1.0 — Stable Linux release

> **Status:** planned · Depends on: v0.5.

## Goal
Something you can hand to a stranger on Linux.

## Scope
- **Packaging:** AppImage, Flatpak, AUR (others by demand). Wayland native, X11 fallback.
- **Reliability:** crash recovery, workspace/session restore, settings migration between versions.
- **Privacy:** telemetry off by default (or none).
- **Docs:** Lua config API reference with an annotated example config, mod authoring guide, plugin and import compatibility list, keybind cheat sheet.
- **Performance:** regression test in CI against the Gate 1 budget.
- **Accessibility pass:** contrast on translucent surfaces, keyboard-only use of every feature, reduced-motion.
- **First-run flow:** theme pick, toolchain detection, starter layout; skippable.

## Out of scope
Windows, macOS, remote development, collaboration, AI features.

## Exit criteria
- [ ] 5 people other than you install it from the packages and finish a real task.
- [ ] No known data-loss bugs.
- [ ] CI blocks a PR that regresses cold start or idle RAM beyond tolerance.

## Post-1.0 parking lot (not commitments)
Windows/macOS · remote/SSH · collaborative editing · AI assist · native-code extension SDK.
